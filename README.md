# Magical Mary (ZDoom/GZDoom versions)
Magical Mary (hastily renamed to "Magical Mary 1: Redthorn's Family Ransom" before the "refactoring hiatus" began) is a first-person shooter and platforming game starring the magical little girl Mary. This archive was used to store the "stable" source code after manually updating my GZDoom fork in a second repository, and now holds all previous released versions. Like anything based on Doom's source code, it's licensed under the GNU GPLv3.
## Download & Setup
To download the last public GZDoom-based version of the game, click this button to read about the release, then download the Windows build and game data at the bottom (in the "assets" section).
* [![Windows x64 download badge](https://img.shields.io/badge/Windows_x64-Download-green.svg)](https://github.com/Xane123/LegacyMagicalMary/releases/tag/v2.1-alpha)
Older versions are listed in the "releases" section, letting you try less complete versions of levels. Some include macOS and Linux builds, but Windows versions work well through Wine on Linux.
